Guía rápida · API v1 y v2

Prueba las rutas de la tienda.

Cada ruta tiene un propósito y un método HTTP. Para consultar productos usa GET; para enviar una compra usa POST.

ⓘ
¿Por qué aparece “405 Method Not Allowed”?Estás haciendo GET en una ruta que solo acepta POST. Para ver productos, usa el botón GET del catálogo.
